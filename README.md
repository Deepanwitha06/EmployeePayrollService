# Employee Payroll Service – Java I/O

## Overview
A Java project demonstrating console input/output, file handling, directory monitoring, and employee payroll file processing.

## Objectives
- Read employee payroll information from the console.
- Perform file and directory operations.
- Monitor directory changes using Java NIO WatchService.
- Write, read, print, and count payroll records.
- Test functionality using JUnit 5.

## Use Cases
- UC1: Read and print employee payroll details.
- UC2: Perform file operations and test the Files API.
- UC3: Monitor a directory using WatchService.
- UC4: Write payroll records to a file.
- UC5: Print payroll file contents.
- UC6: Count payroll entries.
- UC7: Read payroll records for analysis.

## Technologies
- Java 21
- Maven
- Java I/O and Java NIO
- JUnit 5
- Git and GitHub

## Branching Strategy
The main branch contains only this README. The develop branch contains the initial project structure and integrated implementation. Each use case is implemented and tested in its own feature branch before merging into develop.
